# 📧 Email Spam Classifier

An AI-powered Email Spam Classifier built using Python and Machine Learning.

## Features
- Spam/Ham detection
- Web interface
- Machine Learning based prediction

## Technologies
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML/CSS

## Installation
```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000/
